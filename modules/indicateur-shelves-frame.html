Shelves Frame

Signaux de rebond/rejection automatiques sur les étagères Goldbach (0.0, 0.33, 0.66, 1.0) à l'intérieur d'un range PO3. Entry box + TP/SL calibrés sur la structure PO3 elle-même.

Fonctionnalités principales
  • 4 shelves principales (0.0, 0.33, 0.66, 1.0) + extrêmes -0.111 et 1.111
  • Détection arm → confirm close-strict sur chaque shelf
  • Entry box automatique avec TP (shelf suivante) et SL symétrique
  • 10 configurations PO3 (3, 9, 27, 81, 243, 729, 2187, 6561, 19683, 59049)
  • Dashboard position Top/Mid/Bottom Shelf en temps réel
  • Alertes de formation sur chaque confirmation Long/Short

Mode d'emploi
  1. Copier le code Pine ci-dessous (bouton en bas de page, admin).
  2. Sur TradingView Desktop : ouvrir le Pine Editor.
  3. Coller le code, cliquer sur Sauvegarder puis Ajouter au chart.
  4. Ajuster le PO3 Exponent selon ton timeframe (81 intraday, 243 H1, 729 HTF).

Comment trader les signaux

  1. Attendre l'apparition d'une box verte (Long) ou rouge (Short) — cela signifie : arm (mèche traverse la shelf) + confirm (clôture de rejet).
  2. Entrée au centre de la box ("Frame ENTRY ZONE").
  3. TP au niveau indiqué "Frame Safe TP" (généralement la shelf suivante).
  4. SL au niveau "Frame Suggested SL" (calibré sur la structure PO3 elle-même).
  5. Invalidation : si la clôture casse la shelf dans le sens opposé, le setup est annulé.

Conseils : Combiner avec le module Time Cycles (cycles 90mn/30mn) pour timing et avec le Trifecta Institutionnel pour la structure macro. Privilégier les shelves 0.0 et 1.0 (extrêmes de range) pour les setups à forte asymétrie risque/récompense.
