Fix Price, Surgical & CB Intraday

Fix Price automatique à 16:00 ET, niveaux Surgical (N6/N7/N8) et bandes CB Intraday (Base, Expand I/II/III) en pourcentage autour du FP. Labels dynamiques, pas d'étiquettes noires.

Concept

L'indicateur trace autour d'un Fix Price de référence (open de la bougie 16:00 New York par défaut) deux familles de niveaux :

  • Surgical Levels (N6/N7/N8) — niveaux institutionnels fixes à ±0.4375 %, ±0.875 %, ±1.75 % du Fix Price. Idéaux pour identifier les extensions chirurgicales intra-session.
  • CB Intraday (Base / Expand I / II / III) — bandes paramétrables (défauts 0.7 %, 1.3 %, 2 %, 3.5 %). Servent de niveaux de target et d'invalidation pour l'expansion.
  • Fix Price automatique — se cale sur l'open de la bougie 16:00 ET, peu importe le fuseau du chart. Mode manuel disponible.

Les niveaux Surgical (0.4375 / 0.875 / 1.75 %) sont fixes — ce sont des constantes institutionnelles. Les niveaux CB sont paramétrables via les inputs pour s'adapter à ton instrument.
Mode d'emploi — étape par étape
  1. Ajoute l'indicateur sur un chart NQ / ES (ou ton future favori). Timeframe conseillé : 1 min à 15 min pour la détection automatique du Fix Price.
  2. Laisse le mode automatique activé — le Fix Price se cale sur l'open de la bougie 16:00 New York Time. Si tu es sur 4H/Daily, bascule en mode manuel et entre le FP à la main.
  3. Lis le contexte : prix au-dessus du FP = biais long, en-dessous = biais short. La distance au FP te dit quelle zone est active (Base, Expand I, II, III).
  4. Utilise les Surgical comme filtres chirurgicaux : N6/N7 servent de targets rapides, N8 est un seuil de surextension.
  5. Utilise les CB comme carte de l'expansion : cassure nette de CB Base avec volume = continuation probable vers Expand I, puis II. Expand III = zone de retournement statistique.
  6. Combine avec ton biais (True Opens, SSMT, sessions) : trader vers CB Base/E-I/E-II dans le sens du biais HTF, utiliser Expand III comme invalidation ou sortie forcée.
Paramètres (Inputs)
Mode automatique
Active la détection auto du FP à 16:00 ET. Décoche pour entrer un prix manuel.
Fix Price manuel
Utilisé si le mode auto est décoché. Step 0.25 pour coller aux ticks NQ/ES.
Afficher Surgical Levels
Toggle pour masquer/afficher FP + N6/N7/N8.
Afficher CB Intraday
Toggle pour masquer/afficher les bandes CB.
Afficher les labels
Active l'affichage des labels (texte transparent, pas d'étiquette de fond).
Longueur des traits
Nombre de bougies sur lesquelles les lignes s'étendent (défaut 100).
Position label
Droite / Gauche / Centre / sur le trait — pour éviter les chevauchements.
CB Base / E-I / E-II / E-III (%)
Pourcentages des bandes CB. Valeurs par défaut 0.7 / 1.3 / 2 / 3.5. Modifiables.
Expansion Trigger %
Seuil de déclenchement d'expansion (0.1 %) — paramètre réservé à la logique, pas tracé.
Couleurs / Épaisseur / Style
Personnalisables pour chaque niveau (FP, N6/N7/N8, CB Base/E-I/II/III).
Conseils d'utilisation
Timeframe de détection : utilise 1m, 5m, 15m, 30m ou 1H pour que le mode auto capture l'open 16:00 ET. En 4H/Daily/Weekly, bascule sur manuel.
Trader avec les CB : pense les CB comme un ladder. Prix franchit Base avec conviction → objectif Expand I. Franchit Expand I → objectif Expand II. Expand III = zone de retournement (ne jamais y rentrer dans le sens du mouvement).
Piège à éviter : en mode manuel, pense à mettre à jour le FP chaque jour (sinon les niveaux restent calculés sur un vieux prix et deviennent faux).
Timeframes & Marchés
Conçu pour : NQ, ES, futures indices US. Fonctionne aussi sur forex/crypto en mode manuel. TF 1m–15m pour la détection auto.
