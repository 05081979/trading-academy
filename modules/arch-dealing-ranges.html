Module 5 — Dealing Ranges
Assembler PO3 + Goldbach + FIX Price en un seul framework
Les 3 ingrédients du dealing range
1
PO3 sized range — la taille fixe du range (81, 243, 729… selon l'asset)
2
Goldbach levels — les niveaux internes premium/discount
3
Settlement time + FIX price — l'ancre temporelle qui place le range
La formule e=mc²
e = Equilibrium (milieu du range = FIX price)
m = Mean Threshold (VWAP calculé au settlement time)
c² = Paires symétriques Goldbach (premium ↔ discount)
Construction pas à pas
Étape 1Récupérer le FIX price du jour sur CME Group
Étape 2Choisir le bon PO3 range pour l'asset (ex : 729 pour NQ)
Étape 3Positionner le FIX price au centre (0.5) du Goldbach Fib
Étape 4Étendre le fib de ½ PO3 vers le haut et ½ PO3 vers le bas
Étape 5Les niveaux Goldbach (0.03, 0.11, 0.17…) dessinent vos zones
Chaque jour → un dealing range unique
Zone Discount (0.50 → 1.0)
Niveaux : 53, 59, 71, 83, 89, 97
→ Zones d'achat, support
→ Chercher des longs ici
Zone Premium (0 → 0.50)
Niveaux : 3, 11, 17, 29, 41, 47
→ Zones de vente, résistance
→ Chercher des shorts ici
Choisir le bon PO3 : "jouer avec le PO3 number" sur le chart jusqu'à ce que les niveaux Goldbach correspondent visuellement aux structures de prix passées. Les techniques avancées de calcul sont dans le Goldbach Trading book complet.
Application multi-timeframe

Le même framework s'applique à toutes les échelles de temps. Pour la journée : FIX price CME quotidien + PO3 de 729. Pour la semaine : close hebdomadaire. Pour le mois : close mensuel. Pour l'année : close annuel + PO3 de 19 683.
