J Trader Model

Modèle J Trader complet : Key Highs/Lows (PDH/PDL, PWH/PWL, Monday H/L, Asia, London), True Open NY 9:30, macros 9:50 / 10:50 / 11:50 et Juda Swing.

Fonctionnalités principales
  • True Open NY 9:30 tracé et labellisé
  • PDH / PDL (Previous Day High/Low)
  • PWH / PWL (Previous Week High/Low)
  • Monday H/L (Weekly Profile)
  • Asian Range H/L (20:00–03:00 par défaut)
  • London Range H/L (03:00–08:00 par défaut)
  • Macros 9:50, 10:50, 11:50 + Juda Swing
  • POI Time Window (fenêtre de jeu 06:00–17:01)
  • Filtre jours de trading (Monday → Friday)

Mode d'emploi
  1. Copier le code Pine ci-dessous (bouton en bas de page, admin).
  2. Sur TradingView Desktop : ouvrir le Pine Editor.
  3. Coller le code, cliquer sur Sauvegarder puis Ajouter au chart.
  4. Régler les inputs selon votre style (voir Paramètres clés).

Conseils : Combiner True Open + PDH/PDL + Monday H/L pour lire le profil hebdo. Les 3 macros 9:50/10:50/11:50 sont les fenêtres de setup AM prioritaires.
