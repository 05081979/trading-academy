Market Structure (ChoCh / BoS / LQDT)

La structure de marche est detectee via des pivots natifs Pine Script (ta.pivothigh / ta.pivotlow). Aucune librairie externe requise. L'indicateur identifie les ChoCh (retournement) et les BoS (continuation), puis transforme un BoS en LQDT quand le prix sweep le niveau sans cloture au-dela.

ChoCh (Change of Character)

Detecte via des pivots a periode longue (ChoCh Detector Period, defaut 30). Le prix casse un pivot structural dans la direction opposee a la tendance. Signal de retournement. Quand un ChoCh se produit, tout BoS en attente est efface.

BoS (Break of Structure)

Detecte via des pivots a periode courte (BoS & Liquidity Detector Period, defaut 1). Le prix casse un pivot dans la meme direction que la tendance. La ligne est en pointilles (dashed) et se prolonge jusqu'a cassure ou sweep.

LQDT (Liquidite)

Un BoS devient LQDT quand le prix fait un wick a travers le niveau mais cloture de l'autre cote. C'est une prise de liquidite — les stops ont ete touches sans cassure reelle. La ligne passe en dotted violet.

Fast Trend Detector

Option activable (FTD) qui divise par 2 le lookback gauche des pivots ChoCh. Permet une detection plus rapide des retournements, utile en scalping et sur LTF.

Structure MTF (Multi-Timeframe)

L'input Structure Timeframe permet de calculer les pivots sur un HTF (ex: 15m) et de les afficher sur un LTF (ex: 1m). Les 6 pivots (LHP, LLP, SHP, SLP, IHP, ILP) sont calcules via request.security() puis passes a la fonction Structure.

Utilisation

Laissez le champ vide pour utiliser le timeframe du chart. Selectionnez un HTF (ex: "15" pour 15 minutes) pour voir la structure HTF sur votre chart LTF. Tres utile pour voir les ChoCh/BoS du 15m directement sur le chart 1m sans changer de timeframe.

Inducements (IDMT) — Double Systeme

L'indicateur combine deux systemes d'inducement complementaires :

1. IDMT (Pivot-based)

Detecte via des pivots a periode configurable (Inducement Detector Period, defaut 3). Le premier pullback apres un BoS ou ChoCh est marque comme inducement. Ligne pointillee (dotted) etendue jusqu'a invalidation ou sweep.

Mode Sweeps : L'IDMT n'est invalide que si le prix fait un wick a travers + cloture de l'autre cote (sweep). Si le prix cloture au-dela, la ligne est supprimee.

Mode Total : L'IDMT est invalide des que le prix touche le niveau (wick suffit).

2. UAlgo IDM (inside-bar + legs)

Systeme independant base sur les inside bars et le tracking des legs de prix. Quand le prix fait un pullback dans une leg puis que la leg continue (nouveau high/low), le pullback est confirme comme inducement.

IDM = actif (support bullish, ligne rouge), IDM = actif (resistance bearish, ligne verte).

IDM ok = swept (la liquidite a ete prise). Ligne passe en dotted avec couleur attenuee.

Pourquoi deux systemes ?

Le systeme IDMT est lie a la structure formelle (pivots confirmes). Le systeme UAlgo est plus reactif (inside bars, pas de confirmation de pivot). Ensemble, ils couvrent les inducements a differentes echelles — IDMT pour les swings confirmes, UAlgo pour les micro-inducements intra-leg. Maximum 50 UAlgo IDM actifs avec cleanup automatique.

Comment Utiliser
  • Lecture de la structure : Identifiez la tendance via les BoS. Un ChoCh signale un retournement potentiel — cherchez une confirmation.
  • LQDT = piege : Quand un BoS se transforme en LQDT (violet), c'est une prise de liquidite. Le prix a fait un faux breakout — cherchez un trade dans la direction opposee.
  • IDMT comme cible : Les inducements sont des niveaux de piege. Attendez qu'ils soient sweep avant de trader dans la direction opposee.
  • UAlgo IDM ok : Quand un IDM passe en "ok", la liquidite a ete prise. C'est souvent le moment d'un reversal ou d'une continuation forte.
  • MTF Structure : Utilisez le Structure Timeframe pour voir la structure HTF sur votre chart LTF. Ex: structure 15m sur chart 1m pour le timing precis.
  • Confluence : Combinez avec le AA DR OTE MTF (Module 20) pour les niveaux, le AA Macro+News (Module 13) pour le timing.
