Market Structure (BoS / ChoCh)

La base de tout : la structure de marche est detectee via la librairie mickes/PriceAction/4. L'indicateur identifie les pivots (swing H/L), puis detecte les Break of Structure (BoS) et Change of Character (ChoCh) pour determiner la tendance.

BoS (Break of Structure)

Le prix casse un pivot structural dans la meme direction que la tendance. Confirme la continuation. En uptrend : nouveau high au-dessus du previous high.

ChoCh (Change of Character)

Le prix casse un pivot structural dans la direction opposee a la tendance. Signal de retournement potentiel. En uptrend : low casse le previous low.

BSL & SSL (External Liquidity)

BSL (Buyside Liquidity)

Pools de liquidite acheteuse au-dessus des swing highs de structure. Ce sont les stop-loss des vendeurs et les buy-stops des breakout traders. Le prix est attire vers ces niveaux.

SSL (Sellside Liquidity)

Pools de liquidite vendeuse en-dessous des swing lows de structure. Ce sont les stop-loss des acheteurs. Le market maker cible ces niveaux pour alimenter ses positions.

Inducements (IDM) — Double Systeme

L'indicateur combine deux systemes de detection d'inducement complementaires :

1. Retracement IDM (mickes)

Le premier pullback apres un BoS ou ChoCh est marque comme inducement. Ce retracement piege les traders qui entrent trop tot dans le mouvement. L'IDM est invalide au prochain structure break.

IDM avec ligne pointillee etendue jusqu'a invalidation ou sweep.

2. UAlgo IDM (inside-bar + legs)

Systeme base sur les inside bars et le tracking des legs. Detecte les pullbacks dans les legs de prix et les marque comme inducement quand le prix fait un nouveau high/low. Sweep detection automatique.

IDM ✗ = actif, IDM ✓ = swept (pris).

Pourquoi deux systemes ?

Le systeme mickes est lie a la structure formelle (pivots confirmes avec right length). Le systeme UAlgo est plus reactif (inside bars, pas de confirmation). Ensemble, ils couvrent les inducements a differentes echelles — le mickes pour les swings confirmes, UAlgo pour les micro-inducements intra-leg.

Comment Utiliser
  • Lecture de la structure : Identifiez la tendance via les BoS. Un ChoCh signale un retournement potentiel — cherchez une confirmation.
  • Zones de liquidite : Les BSL/SSL vous montrent ou le prix est attire. Tradez AVEC la liquidite, pas contre elle.
  • Grabs vs Sweeps : Un Grab ($$$) = le prix a pris la liquidite et est revenu. Un Sweep ($) = le prix a traverse et continue. Distinction cruciale pour le biais.
  • IDM comme targets : Les inducements sont des niveaux de piege. Quand un IDM est marque, attendez qu'il soit sweep (IDM ✓) avant de trader dans la direction opposee.
  • Turtle Soups : Un sweep suivi d'un ChoCh = signal de retournement fort. C'est le setup ICT classique.
  • Equal H/L : Les equal highs/lows sont des aimants a liquidite. Quand ils apparaissent comme "$$$", le prix ira probablement les chercher.
  • Confluence : Combinez avec le DRT MTF (Module 13) pour les niveaux, les Macros (Module 14) pour le timing.

Notes Techniques
  • Version : Pine Script v6
  • Dependance : mickes/PriceAction/4 (librairie publique TradingView)
  • Overlay : Oui (directement sur le chart)
  • Limites : 500 labels, 500 lignes
  • Multi-TF : Chaque module (Grabs, Sweeps, Equal H/L, etc.) a son propre input timeframe via request.security()
  • UAlgo max : 50 IDM actifs simultanes avec cleanup auto

// AA_Liquidity_Inducements.pine fourni avec ce cours.
//
// Principales sections :
//
// 1. MARKET STRUCTURE (mickes/PriceAction/4)
//    - Pivot detection, BoS, ChoCh, trend tracking
//
// 2. LIQUIDITY GRABS ($$$)
//    - Wick through pivot + close back = grab confirmed
//    - Configurable pivot length, lookback, timeframe
//
// 3. BIG GRABS ($$$)
//    - Same as grabs but with larger pivot settings (HTF)
//
// 4. LIQUIDITY SWEEPS ($)
//    - Wick through pivot + close beyond = sweep confirmed
//    - Filtered: excluded if pivot is a structure break point
//
// 5. TURTLE SOUPS
//    - Sweep + optional ChoCh confirmation = reversal setup
//
// 6. EQUAL HIGHS/LOWS
//    - Pivots within ATR tolerance = equal
//    - Labeled as $$$ (liquidity) or IDM (inducement) based on trend
//    - Sweep detection: when price takes the equal level
//
// 7. BSL & SSL (External Liquidity)
//    - Buyside/Sellside pools at structure pivots
//    - Auto-cleared when price takes the level
//    - Configurable: show last N pools
//
// 8. RETRACEMENT INDUCEMENTS (mickes)
//    - First pullback pivot after BoS/ChoCh = IDM
//    - Extended line until swept or invalidated
//    - Invalidated on next structure break
//
// 9. UALGO INDUCEMENT (inside-bar + legs)
//    - Mother candle tracking (inside bar detection)
//    - Leg high/low tracking with pullback detection
//    - IDM created when pullback is confirmed by new leg extreme
//    - Sweep detection: IDM ✗ (active) → IDM ✓ (swept)
//    - Max 50 active IDMs with auto cleanup
//
// Copiez le fichier .pine complet dans l'editeur Pine de TradingView.
// La librairie mickes/PriceAction/4 sera importee automatiquement.
