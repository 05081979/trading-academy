Trade Plans — 11 Modèles d'Exécution

Plans structurés sur la grille PO3 / Goldbach et les dealing ranges. Chaque plan définit entrée, stop, target et conditions de confluence pour opérer mécaniquement.

Ce module regroupe les 11 trade plans de l'écosystème PO3 / Goldbach. Ils se répartissent en 3 familles :

1. Look Back Trade Plan Mensuel

A monthly play for hundreds of pips

Contexte

  • Utiliser la look back period courante
  • Identifier le numéro en jeu
  • Se situer dans le cycle Manipulation fractal du cycle Accumulation principal

Setup

  • Chercher les clues de la look back partition : taille des gaps, wicks, OB, liquidity runs

Exécution

Stop Loss : 30 pips (pour absorber un PO3 stop run de 27)

Exit : côté opposé du trade, dans la Manipulation principale, après un PO3 stop run, ou à la clôture du cycle

3. OSOK Trade Plan Hebdomadaire

Catch 50 to 75 pips once a week
  1. Capter l'expansion hebdomadaire
  2. Tracer un AMD cycle hebdo (market open → market close)
  3. Attendre que l'Accumulation soit établie
  4. Pendant Manipulation : PO3 stop run de l'acc, puis retrace dans l'acc OU expansion rapide
  5. Attendre une cassure STH/STL
  6. Retrace → OTE sur un niveau Goldbach (peut être non-GB)
Take Profit par partiels : 20 pips → 50 pips → runner 75 pips.
Utiliser les niveaux Goldbach comme zones de partiels logiques.

4. Personal Trade Plan ⭐ Signature

24 pips per week — RR 2.4 — mardi / mercredi / jeudi

Structure en 4 étapes

Step 1
Dans un cycle M (ou M fractal)
Step 2
PO3 stop run sous/sur STH/STL → dans un niveau Goldbach (unfulfilled range)
Step 3
Entrée avec SL 10 pips
Step 4
Target 24 pips dans un Goldbach opposé RR 2.4
Joué principalement sur les zones larges LV et BR (qui contiennent les niveaux non-Goldbach stricts).

Protocole numérique (exemple PO3 = 243)

NuméroValeurRôle

PO3-181 pipsAverage daily range = DR Goldbach
PO3-227 pipsStop run visé
PO3-3/49 / 3 pipsLiquidité visée (gap, block, STH/STL)

Séquence d'exécution

  1. Consolidation PO3-3 pendant la nuit CLS (CE(s)T forex, 18:00 EST indices US)
  2. Fake move hors conso (3 ou 9 pips) → rejeté immédiatement
  3. Prix purge la conso, retrace brièvement, retouche la conso
  4. Anticiper le PO3-2 stop run (27 pips) qui clear la liquidité PO3
  5. Entrée : soit directement au touch du niveau Goldbach, soit après double rejet + retrace

Confirmation par projection daily

  • Mesurer depuis l'asset open time
  • La price projection doit former un pourcentage cible aligné avec le stop run PO3 + liquidité PO3
  • Exemple typique : 0.17%

Confirmation "hors grille"

Tracer un range manuel alignant 3 points : un wick, un block, un gap.

  • Wick aux niveaux 0 / 100 3 / 97
  • Block entre 3 - 11 / 97 - 89
  • Gap entre 11 - 17 / 89 - 83

5. Hidden OTE Trade Plan

OTE entre 2 niveaux Goldbach
  1. Prix s'éloigne d'un niveau Goldbach
  2. Il breach le CE / MT, et possiblement le niveau suivant
  3. Retrace sous CE/MT (discount long, premium short)
  4. Entry à l'OTE : 62 70.5 79
  5. Target : liquidité opposée ou prochain niveau non-touché
Se joue principalement sur zones LV et BR (le CE qu'on veut voir casser).

6. OB Trade Plan 24 pips / DR 81

Order Block → exit au Breaker

Niveaux

3 - 11 - 41 (longs)  ·  97 - 89 - 59 (shorts)

  1. OB formé entre 3-11 (ou 97-89) ou très proche
  2. STH/STL créé, raidé lors de l'expansion away
  3. Retrace vers l'OB = entry
  4. TP au breaker level 41 (ou 59)

7. Breaker Trade Plan 24 pips / DR 81

Breaker → exit au High / Low

Niveaux

59 / 71 ou 41 / 29 + 0 / 100

  1. Breaker formé entre 59-71 (ou 29-41)
  2. Expansion away + STH/STL traversé
  3. Retrace à 71 (ou 29) = entry
  4. Exit au high/low 100 (ou 0)

8. Stop Run Trade Plan 24 pips / DR 81

DR stop run → aim for the Breaker

Niveaux

59 / 71 / 100 / 111 ou 41 / 29 / 0 / -0.111

  1. Prix rejette le HL (ou failed to touch)
  2. Breaker formé dans la breaker zone (59-71 / 29-41)
  3. Expansion away → raid BSL/SSL → stop au PO3 stop run level (111 / -0.111)
  4. Rejet + raid STH/STL opposé
  5. Retrace → stop à l'extrême 100 / 0 = entry (SL derrière le 111)
  6. TP au liquidity void 71 / 29
  7. Monitorer si le breaker devient un "real breaker"

9. Equilibrium Trade Plan 14 pips / DR 81

Mitigation Block & Equilibrium
  1. Prix hovering autour de l'equilibrium (47 / 53)
  2. Buy stops et sell stops clairs entre equilibrium et mitigation block
  3. Entry quand prix hit 47 ou 53
  4. Exit au mitigation opposé

10. FVG Trade Plan

FVG & Propulsion Block

Niveaux

0 / 100 HL  ·  11 / 89 OB  ·  17 / 83 FVG  ·  41 / 59 Breaker

  1. OB créé (peut englober la FVG zone) dans le HL
  2. Prix sort de l'OB + FVG zone, puis revient dans la FVG
  3. Propulsion block formé dans la FVG (max = MT de l'OB)
  4. Cassure du propulsion block (buy/sell on stop) → reprice agressif vers le breaker
  5. Laisse un liquidity void (re-traded plus tard)
