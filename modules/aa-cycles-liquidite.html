Presentation

AA — Cycles & Liquidite est un indicateur overlay complet qui reunit huit modules essentiels en un seul script Pine Script v6. Il permet de visualiser simultanement les cycles temporels trimestriels, la liquidite basee sur les sessions, les niveaux d'ouverture institutionnels, l'equilibre, les retracements de session, la detection de changement de structure (CISD), les probabilites MSB/OB et les blocs HIPPO — le tout directement sur le graphique.

Cycles Trimestriels (QT)

Affiche les cycles QT sur 6 echelles temporelles : Annuel, Mensuel, Hebdomadaire, Journalier, 90 minutes et Micro. Chaque cycle est represente par des boites colorees avec labels identifiant la phase (Q1-Q4, accumulation, distribution, etc.).

Liquidite Temporelle

Detecte les hauts et bas de sessions (Asia, London, AM, PM) et identifie les balayages de liquidite (sweeps). Les niveaux de liquidite sont traces en temps reel avec des alertes visuelles lors des prises de liquidite.

Opens Institutionnels

Trace les niveaux d'ouverture Annuel, Mensuel, Hebdomadaire et Journalier avec des labels clairs. Ces niveaux servent de references institutionnelles pour le biais directionnel et les zones de reaction.

Equilibre (EQ)

Calcule et affiche les niveaux d'equilibre des ranges detectes. L'EQ est le point median ou le prix tend naturellement a revenir — un objectif de haute probabilite depuis n'importe quelle extremite.

Fibs de Session

Trace les retracements Fibonacci bases sur les sessions de trading (Asia, London, New York). Ces niveaux fournissent des zones d'entree et de sortie optimales alignees avec le temps institutionnel.

CISD Multi-Timeframe

Detection du Change In State of Delivery (CISD) sur tous les timeframes de 1 minute a Daily. Le CISD signale un changement dans la livraison du prix — un signal precurseur de retournement majeur.

MSB + OB Probability

Identifie les Market Structure Breaks (MSB) et les Order Blocks avec un calcul de probabilite integre. Detection des zones HPZ (High Probability Zones) ou les OB ont le plus de chances de tenir.

HIPPO Blocks MTF

Les HIPPO Blocks (High Probability Price Observation) sont detectes sur 5 timeframes (15m, 30m, 1H, 4H, Daily). Ce sont des zones ou l'algorithme institutionnel est susceptible de reagir fortement.

Installation
  • 1. Telechargez le fichier .pine via le bouton ci-dessus
  • 2. Ouvrez TradingView et allez dans l'editeur Pine Script (icone {} en bas)
  • 3. Creez un nouveau script, collez le code, et cliquez sur "Ajouter au graphique"
  • 4. L'indicateur s'affiche en overlay — configurez les modules souhaites dans les parametres
  • 5. Conseil : commencez avec un ou deux modules actifs, puis ajoutez progressivement
Guide d'Utilisation
  • QT Cycles : Identifiez la phase du cycle trimestriel actuel (Q1=accumulation, Q2=expansion, Q3=distribution, Q4=decline). Tradez dans le sens de la phase dominante.
  • Liquidite : Surveillez les hauts/bas de session. Un sweep de liquidite (balayage) suivi d'un retournement est un signal de haute probabilite. Les sessions AM et PM offrent les meilleurs mouvements.
  • Opens : Le prix par rapport a l'Open donne le biais. Au-dessus de l'Open = biais haussier, en-dessous = biais baissier. L'Open hebdomadaire est particulierement fiable.
  • Equilibre : L'EQ est votre premier objectif depuis un extremum. C'est aussi une zone de decision : le prix qui traverse l'EQ confirme le biais.
  • CISD : Un CISD sur un timeframe superieur (1H, 4H) valide par un CISD inferieur (5m, 15m) est un signal d'entree puissant. Attendez la confluence multi-TF.
  • MSB + OB : Les MSB confirment le changement de structure. Les OB dans les zones HPZ ont la plus haute probabilite de reaction. Combinez avec le CISD pour des entrees precises.
  • HIPPO : Les blocs HIPPO sur 1H et 4H sont les plus fiables. Cherchez des entrees dans ces zones quand le biais est confirme par les cycles et la structure.
  • Approche combinee : Utilisez les QT Cycles pour le timing macro, la liquidite pour les zones de reaction, les Opens pour le biais, et CISD/MSB/OB/HIPPO pour les entrees precises.
