FULL QT

Toolkit Quarterly Theory complet : cycles A/M/D/R multi-echelles (90min/H1/H4/D/W/M/Y), PSP, TPD, True Opens, Defining Ranges, SSMTs, NWOG/NDOG, triad assets. La reference pour trader QT proprement.

Fonctionnalites principales
  • Cycles QT complets : 90min, H1, H4, D, W, M, Q, Y avec labels A/M/D/R
  • PSP (Precision Swing Point) + TPD (Time Price Divergence) detection automatique
  • True Opens (Daily / Weekly / Monthly / Yearly) avec lignes et labels
  • Defining Ranges + Standard Deviation (0.5, 1, 1.5, 2)
  • SSMT (Sequential SMT) multi-pair : US100/US500, Gold/Silver, EUR/GBP, BTC/ETH, NQ/ES, GC/SI
  • NWOG / NDOG (New Week Opening Gap / New Day Opening Gap)
  • Triad Assets configurables (7 groupes de 3 symboles correles)
  • Alertes integrees sur chaque evenement QT majeur

Mode d'emploi
  1. Copier le code Pine ci-dessous (bouton en bas de page, admin).
  2. Sur TradingView Desktop : ouvrir le Pine Editor (desktop recommande car indicateur lourd).
  3. Coller le code, cliquer sur Sauvegarder puis Ajouter au chart.
  4. Activer d'abord seulement les cycles pertinents pour ton TF (ne pas tout activer sinon chart sature).
  5. Ajouter progressivement True Opens, puis PSP/TPD, puis SSMTs selon ta methodologie.

Comment trader les signaux

  1. Q2 (Manipulation) : cherche un sweep de liquidite (PDH/PDL ou pivot recent). C'est le Judas.
  2. Q3 (Distribution) : apres sweep Q2, direction inverse = signal de continuation dans le vrai move de la session.
  3. PSP confirme : bougie de rejet precise a un niveau cle (True Open, DR, Mid). Entry apres cloture.
  4. TPD (divergence) : prix fait HH/LL mais momentum diverge. Signal de reversal imminent.
  5. SSMT bullish/bearish : un actif du triad casse pas son niveau alors que l'autre oui. Le plus faible se reversera.
  6. NWOG/NDOG : zones de retour magnetique pour ouvrir la semaine/le jour. Souvent mitigees en Q1/Q2.

Conseils : FULL QT est lourd en ressources : desactive ce que tu n'utilises pas. Combine PSP + True Open Daily + SSMT triad pour setups A+. Les True Opens Weekly/Monthly marquent les pivots macro les plus robustes. En backtesting, passe en replay mode et suis les Q1/Q2/Q3/Q4 bougie par bougie pour entrainer l'oeil.
