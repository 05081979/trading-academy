Algo Time & PO3 Ranges

Combine Goldbach Levels (21 niveaux), Algo Time (phases temporelles) et PO3 Sequence (dealing range imbriqué avec zones Order Flow).

Fonctionnalités principales
  • Niveaux Goldbach (0, 3, 11, 17, 23, 29, 35, 41, 47, 50)
  • Zones Order Flow (Liquidity, Execute, Flow gate, Rebalance)
  • Dealing range PO3 dynamique
  • Module Algo Time (phases horaires + SR channels)
  • PO3 Sequence avec sous-ranges imbriqués
  • Time Sequence pour marqueurs temporels
  • Dealing Range Box
  • HUD de statut configurable
Paramètres clés
GB Levels
Active l'affichage des niveaux Goldbach
Algo Time
Active le module Algo Time (phases horaires)
PO3 Sequence
Active la séquence PO3 imbriquée
PO3 Scale
Échelle PO3 du dealing range (9 à 177147)
Price Normalization (Multiplier)
10000 pour forex, 1 pour crypto/indices
Dynamic Range (follows price)
ON = le range suit le prix, OFF = fige jusqu'à sortie
Additional Ranges Up / Down
Nombre de ranges PO3 empilés au-dessus/en-dessous
Show Order Flow Zones
Active les 4 zones Order Flow colorisées
Small (Floating Lines)
Mode lignes courtes flottantes près du prix
Line Style
Style des lignes Goldbach (solide/dot/dash/point)
Show Status Box
Affiche le HUD de statut sur le chart
Dealing Range Box
Dessine la boîte du dealing range actif
Timeframes & Marchés
Toutes timeframes intraday. Forex (multiplier 10000) ou indices/crypto (multiplier 1).
