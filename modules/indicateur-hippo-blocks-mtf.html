HIPPO Blocks MTF

Detecteur automatique de patterns HIPPO (3-bar engulfing gap) sur 5 timeframes simultanes. Chaque HIPPO confirme une zone d'imbalance exploitable comme Order Block ou zone de mitigation.

Fonctionnalites principales
  • Detection HIPPO bullish/bearish sur 5 TF : 15m, 30m, 1H, 4H, Daily
  • Confirmation 3-bougies : gap entre bougie -2 et bougie 0 apres 2 bougies directionnelles
  • Filtre taille minimum configurable (% du corps de la bougie)
  • Box placee avec timestamps HTF reels (precision temporelle parfaite)
  • Couleur distincte par timeframe (visibilite immediate du TF source)
  • Extension horizontale configurable (10 bougies HTF par defaut)
  • Label texte en haut-droite identifiant le TF (H 15m, H 1H, etc.)
Parametres cles
Extend boxes
Nombre de bougies HTF que la box prolonge vers la droite (defaut 10)
Taille min (% corps)
Filtre : HIPPO ignore si gap < X% du corps (defaut 0.01%)
HIPPO 15m / 30m / 1H / 4H / D
Toggle pour afficher les HIPPOs de chaque TF
Couleur par TF
Chaque TF a sa propre couleur pour differencier visuellement
Timeframes & Marches
S'utilise sur un chart intraday (M1-M15 ideal). Les HIPPOs detectes sur 15m/30m/1H sont les plus actionnables en scalping/day trading. Les HIPPOs 4H/D sont des zones HTF a utiliser comme cibles ou filtres de direction.
Mode d'emploi
  1. Copier le code Pine ci-dessous (bouton en bas de page, admin).
  2. Sur TradingView Desktop : ouvrir le Pine Editor.
  3. Coller le code, cliquer sur Sauvegarder puis Ajouter au chart.
  4. Activer uniquement les TF pertinents pour ton style (ex: 15m+1H en intraday, 1H+4H+D en swing).
  5. Ajuster Extend boxes selon la densite des HIPPOs (plus c'est dense, plus tu reduis).

Comment trader les signaux

  1. HIPPO Bullish (vert) : 2 bougies haussieres puis gap haussier. Zone entre low[1] et high[2] = support institutionnel.
  2. HIPPO Bearish (rouge) : 2 bougies baissieres puis gap baissier. Zone entre high[1] et low[2] = resistance institutionnelle.
  3. Entry au retest du bord interieur de la box (cote oppose a la direction HIPPO).
  4. SL au-dela du bord exterieur de la box + 1-2 ticks de tampon.
  5. TP = prochaine liquidite (EQH/EQL, PDH/PDL, HIPPO suivante dans le sens du trade).
  6. Invalidation : cloture complete au-dela du HIPPO = zone consommee, chercher ailleurs.

Conseils : Un HIPPO 4H/D qui overlap avec une shelves Goldbach ou un niveau Trifecta = setup A+. Combiner avec Quarterly Theory pour valider le timing (Q2 Manipulation + HIPPO = haute probabilite). Ne pas trader les HIPPOs contre la direction du Full QT macro.
