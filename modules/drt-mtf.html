DRT MTF — Dealing Range Theory

Indicateur multi-timeframe base sur la theorie des Dealing Ranges (mickes). Identifie les ranges de prix via les pivots de liquidite et affiche les niveaux High, Low, EQ (50%), 75% et 25% sur 8 timeframes simultanement.

Qu'est-ce que le DRT ?

La Dealing Range Theory identifie les zones de prix ou les institutions ont effectue des transactions significatives. Un Dealing Range se forme lorsqu'un pivot de prix prend la liquidite d'un pivot precedent — creant ainsi un range institutionnel entre le High et le Low de ces pivots.

Pivot de Liquidite (Buyside)

Un pivot haut qui represente un pool de liquidite acheteuse. Lorsqu'un nouveau pivot haut depasse ce niveau, il "prend" cette liquidite et definit le High du Dealing Range.

Pivot de Liquidite (Sellside)

Un pivot bas qui represente un pool de liquidite vendeuse. Lorsqu'un nouveau pivot bas casse ce niveau, il "prend" cette liquidite et definit le Low du Dealing Range.

Equilibrium (EQ / 50%)

Le milieu exact du Dealing Range. C'est le niveau le plus important — il separe la zone Premium (au-dessus) de la zone Discount (en-dessous). Le prix est attire vers cet equilibre.

Niveaux 75% / 25%

Niveaux intermediaires qui servent de reperes pour les entrees et sorties. 75% = deep premium, 25% = deep discount. Les meilleurs trades ICT se font a ces extremes.

Multi-Timeframe : 8 TF Simultanes

L'indicateur calcule le Dealing Range sur chaque timeframe via request.security() et les affiche tous simultanement sur votre chart. Chaque TF a sa propre couleur configurable.

Zones Premium / Discount

Zone Premium (au-dessus EQ)

Zone ou le prix est "cher" par rapport au Dealing Range. C'est la zone ideale pour vendre (shorts). Le tableau affiche Premium en rouge quand le prix est dans cette zone.

Zone Discount (en-dessous EQ)

Zone ou le prix est "pas cher". C'est la zone ideale pour acheter (longs). Le tableau affiche Discount en vert quand le prix est dans cette zone.

Tableau de Synthese (Top Right)

Un tableau en haut a droite du chart affiche en temps reel pour chaque TF actif : le TF, la zone (Premium/Discount/Above/Below) et le niveau EQ. Cela permet de voir d'un coup d'oeil l'alignement multi-timeframe.

Comment Utiliser
  • Confluence MTF : Cherchez un alignement — si 1H, 4H et D sont tous en "Discount", c'est un signal fort pour un long.
  • EQ comme target : Quand le prix est en discount extreme (25%), visez l'EQ (50%) comme premier objectif.
  • Rejection aux niveaux : Les lignes High/Low/75%/25% agissent comme S/R dynamiques. Cherchez des rejections avec volume.
  • Combinaison : Utilisez avec les ICT Macros (Module 14) pour timer vos entrees dans les fenetres macro au sein du dealing range.
  • Parametres pivots : Pivot Length de 20 par defaut — augmentez pour des ranges plus larges (swing), reduisez pour du scalping.

// ─── TYPES (from mickes) ────────────────────────────────────
type Pivot
    float Price
    int   Time
    int   TimeClose
    string Timeframe

type DealingRangePivot
    bool  New
    float Price
    int   Time
    Pivot TakenLiquidityPivot

type DealingRangeData
    array<Pivot> BuysideLiquidityPivots
    array<Pivot> SellsideLiquidityPivots
    DealingRangePivot High
    DealingRangePivot Low

type Settings
    int  PivotLeftLength
    int  PivotRightLength
    bool ForceClosedBar
    int  LiquidityPivotLeftLength
    int  LiquidityPivotRightLength

// ─── CORE FUNCTIONS (from mickes) ───────────────────────────
CreateLiquidityPivots(Settings settings) =>
    pivotHigh = ta.pivothigh(settings.LiquidityPivotLeftLength, settings.LiquidityPivotRightLength)
    pivotLow  = ta.pivotlow(settings.LiquidityPivotLeftLength, settings.LiquidityPivotRightLength)
    pivotHighPivot = (settings.ForceClosedBar and barstate.isconfirmed) or not settings.ForceClosedBar ?
      Pivot.new(pivotHigh, time[settings.LiquidityPivotRightLength], time_close[settings.LiquidityPivotRightLength], timeframe.period) : na
    pivotLowPivot = (settings.ForceClosedBar and barstate.isconfirmed) or not settings.ForceClosedBar ?
      Pivot.new(pivotLow, time[settings.LiquidityPivotRightLength], time_close[settings.LiquidityPivotRightLength], timeframe.period) : na
    [pivotHighPivot, pivotLowPivot]

Liquidity(DealingRangeData dr, Pivot pivotHigh, Pivot pivotLow) =>
    if not na(pivotHigh) and not na(pivotHigh.Price)
        dr.BuysideLiquidityPivots.unshift(pivotHigh)
    if not na(pivotLow) and not na(pivotLow.Price)
        dr.SellsideLiquidityPivots.unshift(pivotLow)

CreateDealingRangePivots(Settings settings) =>
    pivotHigh = ta.pivothigh(settings.PivotLeftLength, settings.PivotRightLength)
    pivotLow  = ta.pivotlow(settings.PivotLeftLength, settings.PivotRightLength)
    pivotHighPivot = (settings.ForceClosedBar and barstate.isconfirmed) or not settings.ForceClosedBar ?
      Pivot.new(pivotHigh, time[settings.PivotRightLength], time_close[settings.PivotRightLength], timeframe.period) : na
    pivotLowPivot = (settings.ForceClosedBar and barstate.isconfirmed) or not settings.ForceClosedBar ?
      Pivot.new(pivotLow, time[settings.PivotRightLength], time_close[settings.PivotRightLength], timeframe.period) : na
    [pivotHighPivot, pivotLowPivot]

DealingRangeCalc(DealingRangeData dr, Pivot pivotHigh, Pivot pivotLow) =>
    if not na(pivotHigh) and not na(pivotHigh.Price)
        for liquidityPivot in dr.BuysideLiquidityPivots
            if pivotHigh.Time > liquidityPivot.Time and pivotHigh.Price > liquidityPivot.Price
                readdLiquidityPivot = dr.BuysideLiquidityPivots.shift()
                dr.BuysideLiquidityPivots.clear()
                dr.BuysideLiquidityPivots.unshift(readdLiquidityPivot)
                dr.High := DealingRangePivot.new(true, pivotHigh.Price, pivotHigh.Time, liquidityPivot)
                break
    if not na(pivotLow) and not na(pivotLow.Price)
        for liquidityPivot in dr.SellsideLiquidityPivots
            if pivotLow.Time > liquidityPivot.Time and pivotLow.Price < liquidityPivot.Price
                readdLiquidityPivot = dr.SellsideLiquidityPivots.shift()
                dr.SellsideLiquidityPivots.clear()
                dr.SellsideLiquidityPivots.unshift(readdLiquidityPivot)
                dr.Low := DealingRangePivot.new(true, pivotLow.Price, pivotLow.Time, liquidityPivot)
                break

drt_full(Settings settings) =>
    var DealingRangeData dr = DealingRangeData.new(
      array.new<Pivot>(), array.new<Pivot>(),
      DealingRangePivot.new(), DealingRangePivot.new())
    [liqH, liqL] = CreateLiquidityPivots(settings)
    Liquidity(dr, liqH, liqL)
    [drH, drL] = CreateDealingRangePivots(settings)
    DealingRangeCalc(dr, drH, drL)
    float h = not na(dr.High) ? dr.High.Price : na
    float l = not na(dr.Low)  ? dr.Low.Price  : na
    [h, l]

f_draw(bool show, string tfStr, float rH, float rL, color col, int rEdge,
       array<line> aL, array<label> aLb, array<box> aB) =>
    if show and not na(rH) and not na(rL) and rH != rL
        float rng  = rH - rL
        float lv75 = rL + rng * 0.75
        float lv50 = rL + rng * 0.50
        float lv25 = rL + rng * 0.25
        int   lft  = bar_index
        color lCol = f_lineCol(col)
        int   eqW  = lineW + 1 > 4 ? 4 : lineW + 1
        if showHigh
            aL.push(line.new(lft, rH, rEdge, rH, color=lCol, width=lineW, style=line.style_solid))
        if showLow
            aL.push(line.new(lft, rL, rEdge, rL, color=lCol, width=lineW, style=line.style_solid))
        if show75
            aL.push(line.new(lft, lv75, rEdge, lv75, color=lCol, width=lineW, style=line.style_dotted))
        if show50
            aL.push(line.new(lft, lv50, rEdge, lv50, color=lCol, width=eqW, style=line.style_dashed))
        if show25
            aL.push(line.new(lft, lv25, rEdge, lv25, color=lCol, width=lineW, style=line.style_dotted))
        if showLabels
            if lblShowH
                aLb.push(label.new(rEdge + 1, rH, "High", style=label.style_none, textcolor=colLabel, size=labelSz))
            if lblShowL
                aLb.push(label.new(rEdge + 1, rL, "Low", style=label.style_none, textcolor=colLabel, size=labelSz))
            if lblShow75
                aLb.push(label.new(rEdge + 1, lv75, "0.75", style=label.style_none, textcolor=colLabel, size=labelSz))
            if lblShow50
                aLb.push(label.new(rEdge + 1, lv50, tfStr + " EQ", style=label.style_none, textcolor=colLabel, size=labelSz))
            if lblShow25
                aLb.push(label.new(rEdge + 1, lv25, "0.25", style=label.style_none, textcolor=colLabel, size=labelSz))
        if showZones
            aB.push(box.new(lft, rH,   rEdge, lv50, bgcolor=premiumCol,  border_color=color.new(color.white, 100)))
            aB.push(box.new(lft, lv50, rEdge, rL,   bgcolor=discountCol, border_color=color.new(color.white, 100)))

zoneText(float rH, float rL, float c) =>
    if na(rH) or na(rL) or rH == rL
        "—"
    else
        float lv50 = rL + (rH - rL) * 0.50
        c >= rH ? "Above" : c >= lv50 ? "Premium" : c >= rL ? "Discount" : "Below"

zoneColor(float rH, float rL, float c) =>
    if na(rH) or na(rL) or rH == rL
        color.gray
    else
        float lv50 = rL + (rH - rL) * 0.50
        c >= lv50 ? #EF5350 : #26A69A
