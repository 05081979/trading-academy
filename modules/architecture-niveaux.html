Section 01 — Fondations

Power of Three (PO3)

Le Power of Three (PO3) est le fondement mathematique de l'ensemble du framework. Il designe les puissances de 3, qui definissent la taille de tous les dealing ranges institutionnels.

Sequence des Puissances de 3

Chaque nombre est le triple du precedent. Cette progression forme l'architecture fractale des marches :

PuissanceValeurUsage Typique
3^13Micro-range, scalping
3^29Range de session
3^327Range intraday court
3^481Range journalier standard
3^5243Range multi-jours
3^6729Cycle principal (Institutionnel)
3^72187Cycle swing
3^86561Macro-cycle

Nature Fractale

Regle fondamentale : 3 ranges de taille N = 1 range de taille N x 3.

Exemple : 3 ranges de 81 points = 1 range de 243 points. 3 ranges de 243 = 1 range de 729.

Cette auto-similarite est la cle de la structure des marches a toutes les echelles de temps.

  • Emboitement : Chaque range contient exactement 3 sous-ranges
  • Scalabilite : Le meme comportement se repete du tick au cycle annuel
  • Symetrie : Le midpoint (50%) de chaque range est toujours significatif
  • Predictibilite : Une fois le range identifie, les targets sont mathematiques
Le marche ne se deplace pas de maniere aleatoire. Il livre le prix en increments de puissances de 3, creant une structure fractale parfaitement emboitee.
Section 02 — Fondations

Niveaux Institutionnel

Bases sur la conjecture de Christian Institutionnel (1690-1764), ces niveaux definissent les zones de reaction du prix a l'interieur de chaque dealing range.

La Conjecture

Conjecture de Institutionnel : Tout nombre pair superieur a 2 peut s'exprimer comme la somme de deux nombres premiers.

Pour 100 : il existe 6 partitions de nombres premiers, plus les bornes 0 et 100.

Les 6 Partitions de 100

Symetrie autour de 50% : Chaque paire de niveaux est symetrique par rapport au midpoint. Si 29% reagit en bas, 71% reagira en haut. Cette symetrie est la signature de la livraison algorithmique.

Niveaux Non-Institutionnel (NGB)

  • Definition : Zones entre les niveaux Institutionnel ou aucun premier ne forme de partition
  • Role : Zones de transition — le prix les traverse sans s'arreter
  • Trading : Ne jamais entrer dans une zone NGB ; attendre un niveau Institutionnel

Niveaux CE (Consequent Encroachment)

  • Definition : Points medians entre deux niveaux Institutionnel adjacents
  • Role : Niveaux secondaires de reaction, confirmation de direction
  • Calcul : CE = (Institutionnel_A + Institutionnel_B) / 2

Institutionnel FIB

Outil Fibonacci Institutionnel : Reticule de Fibonacci ou les niveaux standard (23.6, 38.2, 50, 61.8, 78.6) sont remplaces par les niveaux Institutionnel :

0, 3, 11, 17, 29, 41, 47, 50, 53, 59, 71, 83, 89, 97, 100

Application : tracer du Low au High du range (ou inversement) pour obtenir les niveaux de reaction precis.

Section 03 — Fondations

Fix CME 16h00 NY

Le Fix Price est le prix de reference institutionnel calcule chaque jour a 16h00 heure de New York. C'est l'ancre du cycle journalier autour de laquelle tout le systeme s'articule.

Calcul du Fix

Methode VWAP 30 secondes : Le Fix est calcule comme le prix moyen pondere par le volume (VWAP) sur la fenetre de 15h59:30 a 16h00:00 NY. Ce calcul est effectue par le CME pour les contrats futures.
ParametreDetail
Heure exacte16h00:00 New York (Eastern Time)
Fenetre VWAP30 secondes (15:59:30 a 16:00:00)
InstrumentsTous les futures CME (ES, NQ, YM, RTY...)
RoleAncre du dealing range journalier, situe au MID (50%)

Le Cycle du Fix

  1. Fix reinitialise : A 16h00 NY, le prix de reference est etabli. Le cycle commence.
  2. Nuit (Asia) : Le prix s'eloigne du Fix pendant la session asiatique, creant le mouvement initial.
  3. Europe : La session europeenne amplifie ou corrige le mouvement nocturne.
  4. US (NY AM/PM) : La session americaine ramene le prix vers le nouveau Fix a 16h00.
  5. Nouveau Fix : Le cycle se reinitialise. Le processus recommence.

Targets Typiques par Rapport au Fix

Niveaux de target les plus frequents :

41% / 59% : Targets proches du Fix, jours de faible volatilite

71% : Target standard, jours normaux (le plus frequent)

83% : Target etendu, jours de news ou forte volatilite

89% / 97% : Jours exceptionnels, sweeps de liquidite complets

Le Fix n'est pas un simple prix de cloture. C'est le point d'equilibre algorithmique autour duquel le marche livre ses ordres sur 24 heures.
Section 04 — Structure

Dealing Ranges PO3

Les Dealing Ranges sont les zones de prix definies par une hauteur en puissances de 3. Ce sont les "boites" dans lesquelles le prix oscille et livre ses ordres.

Definition et Construction

  • Taille : Toujours une puissance de 3 (27, 81, 243, 729 points)
  • Bornes : Low = 0%, High = 100% du range
  • Midpoint : 50% du range, souvent ou se situe le Fix Price
  • Niveaux internes : Tous les niveaux Institutionnel (3,11,17,29,41,47,50,53,59,71,83,89,97)

Empilement Fractal

Principe d'empilement : Les ranges s'empilent comme des etages d'un immeuble. 3 sous-ranges forment toujours 1 range superieur.

Etage 1 (sous-sol) : 3 ranges de 27 = 1 range de 81

Etage 2 (rez-de-chaussee) : 3 ranges de 81 = 1 range de 243

Etage 3 (principal) : 3 ranges de 243 = 1 range de 729

Comportement du Prix dans un Range

ComportementDescription
OscillationLe prix oscille entre les bornes du range (0% et 100%)
Respect du MIDLe midpoint (50%) agit comme un aimant — le prix y revient regulierement
Wicks vs BodiesLes meches (wicks) peuvent sortir du range, mais les corps de bougie restent a l'interieur
Sweep et retourLe prix sweep une borne puis retourne vers l'interieur

Mecanique de Liquidite

  1. Accumulation : Le prix consolide dans une zone etroite du range
  2. Sweep (Manipulation) : Le prix casse une borne pour capturer la liquidite (stop loss)
  3. Retour vers l'equilibre : Le prix revient rapidement vers le midpoint ou la borne opposee
  4. Distribution : Le mouvement directionnel se produit, delivrant les ordres institutionnels
Regle critique : Si le corps d'une bougie cloture en dehors du range sur un timeframe significatif, le range est considere comme "rompu" et un nouveau range doit etre identifie.

Le HIPPO est un point de prix cache ou les institutions ont positionne leurs ordres. Sa force depend de sa position dans le range, de sa relation avec le Fix, et du type de formation sur lequel il repose.

Un HIPPO au-dela de l'IMP10 est un objectif secondaire, moins probable.

Les IMP Nodes sont les niveaux de saturation du mouvement journalier, derives des circuit breakers du CME. Ils definissent les targets maximales attendues pour chaque session.

Derivation des Circuit Breakers

Section 07 — Contexte

Institutionnel PO3 729

Le range Institutionnel 729 est le cycle principal du framework. Il s'etend du Cycle Low au Cycle High sur 729 points et contient l'integralite de la structure de livraison.

Structure du Range 729

ElementPositionDetail
Cycle Low0% (borne basse)Point bas du cycle — base de l'accumulation
Cycle High100% (borne haute)Point haut du cycle — sommet de la distribution

Range Total729 points3^6 = 729, le coeur du systeme

Les 3 Zones de Comportement

Zone Basse (0-33%) : Zone d'accumulation. Le prix construit une base, les institutions accumulent. Les sweeps sous le Cycle Low sont des pièges.
Zone Mediane (33-66%) : Zone de transition. Le Fix Price se situe ici. Le prix oscille autour de l'equilibre. C'est la zone "neutre" ou les biais sont les plus difficiles a lire.
Zone Haute (66-100%) : Zone de distribution. Les institutions livrent leurs positions accumulees en bas. Les rallyes au-dessus du Cycle High sont des sweeps de liquidite.

AlgorithmeSequenceDescription
Algo 1 (Haussier)Low → MID → HighAccumulation en bas, distribution progressive vers le haut. Le prix monte methodiquement en respectant les niveaux Institutionnel.
Algo 2 (Baissier)High → MID → LowDistribution en haut, re-accumulation vers le bas. Le prix descend en cascades, niveaux apres niveaux.

Decomposition Fractale du 729

  • 3 x 243 : Le range 729 contient 3 sous-ranges de 243 points (tiers inferieur, median, superieur)
  • 9 x 81 : Chaque sous-range de 243 contient 3 ranges de 81 points (9 au total)
  • 27 x 27 : Chaque range de 81 contient 3 ranges de 27 points (27 au total)
  • Principe : L'analyse commence au 729 et zoom progressivement pour l'execution
Section 08 — Temps

Institutionnel Time

Le Institutionnel Time est le systeme de temps algorithmique du framework. Il traduit l'heure en numeros Institutionnel pour identifier les moments precis ou le prix est susceptible de reagir.

Calcul du Numero GB Time

Methode : Le numero Institutionnel Time est la somme des heures et des minutes en heure de Zurich.

Exemple : 15h41 Zurich → 15 + 41 = 56. On cherche si 56 est un niveau Institutionnel significatif.

Autre exemple : 09h20 Zurich → 9 + 20 = 29. Le 29 est un niveau Institutionnel actif.

Buffer et Validation

Regle du buffer +/-1 minute : Une reaction est consideree comme "on time" si elle se produit dans une fenetre de +/-1 minute autour du GB Time calcule.

Exemple : si le GB Time target est 29, la fenetre valide est de la minute qui donne 28 a la minute qui donne 30.

Regle d'Interchangeabilite

71 et 77 sont interchangeables : Une reaction a 71 ou 77 valide le meme signal temporel.

29 et 35 sont interchangeables : Meme principe pour la zone basse du spectre temporel.

Cette interchangeabilite reflete la flexibilite de l'algorithme dans des zones proches.

Past Targets vs Future Targets

  • Past Targets : Niveaux GB Time deja passes — confirment que l'algorithme est actif si le prix a reagi
  • Future Targets : Prochains niveaux GB Time — permettent d'anticiper les fenetres de reaction
  • Validation : 2 Past Targets confirmes = forte probabilite que le prochain Future Target sera respecte
  • Inducement : Le lien avec l'inducement se fait quand le prix atteint un niveau Institutionnel (prix) exactement au moment d'un niveau Institutionnel (temps)

L'alignement du prix (Institutionnel spatiale) et du temps (Institutionnel temporel) au meme moment cree ce qu'on appelle la "confluence absolue" — le moment le plus probable pour un mouvement directionnel.

Conditions d'Entree

  4. Confirmer le reversal : Un HIPPO ou un OB doit etre present au point de retournement

Principe de la Mitigation

Definition : La mitigation est le processus par lequel le prix retourne a un point d'interet (OB, FVG, Breaker) pour "combler" le desequilibre laisse par un mouvement precedent.

Le Mitigation Plan exploite ce retour pour entrer dans la direction du mouvement suivant, avec une target etendue de 40 handles.

Conditions du Setup

  4. Aligner avec le Institutionnel : Le POI doit se situer sur un niveau Institutionnel (idealement 17% ou 83%)

La Couche de Liquidite

La couche de liquidite est l'un des mecanismes les plus precis du systeme. Trois niveaux institutionnels sont actifs a l'interieur de chaque dealing range. Cette couche definit comment le prix interagit avec la liquidite interne et externe du range.

Fonctionnement de la Couche

Quand le prix approche un extremite du range (le high ou le low), le marche cree deliberement un swing pour generer de la liquidite. Ce swing forme ce qu'on appelle l'IRV (Internal Range Validity) — la validite interne du range.

Les traders retail se positionnent a l'achat, placant leurs stop-loss juste au-dela du swing nouvellement forme. Le prix inverse ensuite, balaie cette liquidite de stops, puis est typiquement propulse au minimum jusqu'a l'extremite opposee du range.

Au-dela du Range : l'ERD

Le plus souvent, le prix depasse le range et se dirige vers les niveaux du dealing range suivant. On appelle cela l'ERD (External Range Delimit) — la delimitation externe du range.

A ce point, deux scenarios se presentent :

  1. Rejet : Le prix rejette la liquidite externe et inverse — il retourne dans le range d'origine
  2. Continuation : Le prix echoue a rentrer dans le range precedent, rejette l'extremite et commence a trader dans le nouveau dealing range
Regle de transition

Quand le scenario 2 se produit (continuation), il faut basculer vers un range PO3 plus large. Cela donne une vision plus claire de la structure de marche globale.

Le Troisieme Niveau : le GIP

Au sein de la couche de liquidite, il existe un troisieme niveau cle : le GIP (Point d'Inversion Institutionnel). Ce niveau a une nature speciale — c'est le point ou le prix a la plus forte probabilite d'inversion dans le cycle.

Fractalite de la Couche

Ce mecanisme IRV → ERD fonctionne egalement sur les ranges fractals qui se situent entre deux niveaux institutionnels, a condition que la taille du range PO3 soit suffisamment grande pour que les niveaux soient exploitables.

Synthese du Framework Architecture des Niveaux

Le systeme repose sur 5 piliers interconnectes :

1. PO3 : La structure fractale des ranges (puissances de 3)

2. Institutionnel : Les niveaux de reaction a l'interieur des ranges

3. Fix CME : L'ancre du cycle journalier (16h00 NY)
