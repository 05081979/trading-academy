Dealing Ranges

Un dealing range PO3 se construit avec trois choses : une taille PO3, des niveaux PO3 internes, et un prix d’ancrage.

  1. Choisir un PO3
  2. Trouver le prix d’ancrage
  3. Tracer le range 0 → 100
  4. Placer les partitions PO3
  5. Observer comment le prix délivre d’un niveau à l’autre

Idées clés

  • Le range te donne directement des highs/lows possibles
  • Le prix peut stopper, reverser, ou passer au range suivant
  • Le niveau 50 = EQ
  • Le range peut être fixe, optimal ou dynamique selon l’approche
En pratique : le range n’est pas là pour décorer le graphe. Il sert à sentir où le prix est et où il peut raisonnablement aller.

Choix du bon range

Méthode 1 — Auto PO3

  • Plus efficace sur les lower timeframes
  • Génère plus de niveaux
  • Très utile pour intraday
  • Conseil débutant : TP à EQ

Méthode 2 — ADR

  • Trouver l’ADR
  • Prendre le PO3 le plus proche
  • Moins de niveaux, mais souvent plus lourds
  • Utile pour cadrer MMXM et ranges non remplis

Repères donnés dans les docs

  • 243 : intraday principal
  • 729 : weekly profile / 4H ou 1H
  • 2187 : bigger picture, à ne pas trop dépasser

Algo 1 & Algo 2

Algo 1 = MMXM

High / Low → Order Block → Premium Breaker → Premium Rejection Block → Premium FVG → Discount Liquidity Void

Algo 2 = Trending

Rejection Block → Breaker → FVG → Opposing Order Block → Premium Mitigation → Premium Liquidity Void

Lecture pratique

  • Algo 1 = structure plus macro, type Market Maker Model
  • Algo 2 = version tendance, souvent visible en fractale dans Algo 1
  • La zone FVG est la plus importante pour l’entrée
  • EQ et l’OB opposé servent souvent de terminus intermédiaires
Les PDFs rappellent que l’algo n’est pas un bouton magique. Il peut ralentir, se décaler, s’inverser, ou être lu différemment selon le timeframe.

AMD

AMD reste la grammaire de base : accumulation, manipulation, distribution. Les docs le relient à la lecture fractale du temps et à la distorsion temporelle.

HIPPO

HIPPO = Hidden Interbank Price Point Objective. C’est un PD Array basé sur une formation à 2 bougies avec overlapping wicks.

  • 2 bougies avec mèches qui se chevauchent
  • Idéalement FVG / MVG au-dessus et au-dessous
  • Plus fort si les FVG environnants ont une taille PO3 identique
  • Très intéressant près d’un CE ou d’un niveau non PO3
  • Peut servir de draw on liquidity, inversion, support ou résistance

HIPPO POT A MUS

  1. Identifier le HIPPO
  2. Voir s’il y a un swing / POT autour
  3. Attendre activation dans la zone
  4. Le FVG autour doit tenir

Circuit Breakers / Twin Tower

Prix de référence

  • VWAP de la bougie 30 secondes entre 3:59:30 PM et 4:00 PM EST
  • Approximation pratique : EQ de cette bougie

Bornes

  • Statique : ±7% sur la session
  • Dynamique : ±3.5% dans une heure
  • Dans Twin Tower, retour fréquent des chiffres 7, 13, 20

Lecture Twin Tower

  • E = Equilibrium
  • M = Mean Threshold
  • C² = Circuit breaker dealing ranges au-dessus et au-dessous
  • Le temps du settlement / fix est indispensable
Sans le bon timing de settlement, tu n’as pas le bon prix de référence. Donc ton cadre peut être faux dès le départ.
