Macro Tracker & News

Trace les fenêtres de macros ICT intrajournalières (≈30 min) + calendrier Forex Factory via toodegrees. Projections futures, lignes verticales, filtres impact & devise.

Fonctionnalités principales
  • Macros ICT intrajour (London, AM, PM, Lunch, Close) avec projections
  • Mode On Chart ou New Pane
  • Lignes verticales aux starts de chaque macro
  • Calendrier Forex Factory intégré (impact haut / moyen / bas)
  • Filtres par devise (USD, EUR, GBP, JPY, etc.)
  • Labels texte + fond coloré par macro
  • Projections macros futures (fenêtres à venir)
  • Marqueurs New Day / Midnight NY
Paramètres clés
Mode
Affichage On Chart ou dans un New Pane séparé
Largeur de ligne
Épaisseur du trait des fenêtres macros (1-4 px)
Labels / Temps / Projections
Toggles pour libellés, timer et projections futures
Vertical Lines
Lignes verticales au start de chaque macro (couleur/style/épaisseur)
News Calendar 🔴🟠🟡
Filtre impact haut / moyen / bas (Forex Factory)
Devises
Filtre par devise affichée (USD, EUR, GBP, JPY, CHF, CAD, AUD, NZD)
Macros London / AM / Lunch / PM / Close
Active individuellement chaque fenêtre macro ICT
Couleurs macros
Couleur de fond et de ligne de chaque macro
Timeframes & Marchés
TF entre 30 secondes et Daily (contrôle intégré). Optimal : 1m à 15m sur indices US (ES / NQ) et FX majeurs.
Mode d'emploi
  1. Copier le code Pine ci-dessous (bouton en bas de page, admin).
  2. Sur TradingView Desktop : ouvrir le Pine Editor.
  3. Coller le code, cliquer sur Sauvegarder puis Ajouter au chart.
  4. Régler les inputs selon votre style (voir Paramètres clés).

Conseils : Filtrer les news sur USD + impact rouge pour ne voir que les catalyseurs qui bougent les indices. Activer projections pour anticiper la prochaine macro.
