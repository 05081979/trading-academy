HTF Candles

Affiche jusqu'à 12 bougies HTF à droite du chart avec FVG, Volume Imbalance et trace lines. Labels, timer, Day-of-Week et custom daily open (Midnight / 8:30 / 9:30).

Fonctionnalités principales
  • Jusqu'à 12 HTF candles affichées à droite (HTF1 à HTF12)
  • Fair Value Gaps HTF avec mitigation et half-line (50%)
  • Volume Imbalance détectées sur chaque HTF
  • Trace lines Open/Close/High/Low projetées vers le prix courant
  • Labels HTF personnalisables + timer de fin de bougie (dd/hh/mm/ss)
  • Day-of-Week labels sur la bougie Daily
  • Custom daily open : Midnight / 8:30 ET / 9:30 ET
  • Option TF non-multiples + buffer 50 bars max
Paramètres clés
HTF 1 à HTF 12
Active chaque timeframe HTF individuellement avec sa propre résolution
Limit to next HTFs only
Limite dynamique du nombre de HTFs affichés (1-12)
Allow non-multiples
Autorise des HTFs qui ne sont pas multiples du TF chart
Custom daily candle open
Ouverture de la Daily : Midnight / 8:30 / 9:30 (heure NY)
Fair Value Gap
Affiche les FVG dans les bougies HTF (toutes ou mitigées)
Half FVG line
Trace la ligne médiane (50%) du FVG
Volume Imbalance
Affiche les Volume Imbalances sur les HTF
Trace lines O/C/H/L
Projette Open/Close/High/Low des HTF vers la bougie courante
HTF Label
Étiquette du TF sur chaque bougie HTF
Remaining time
Timer temps restant avant clôture HTF
Day-of-Week labels
Labels jour de la semaine sur la Daily
Bull/Bear colors
Couleurs personnalisables corps / bordures / mèches
Timeframes & Marchés
TF basses conseillées (1m–15m). Fonctionne sur tout marché TradingView (indices, FX, crypto).
Mode d'emploi
  1. Copier le code Pine ci-dessous (bouton en bas de page, admin).
  2. Sur TradingView Desktop : ouvrir le Pine Editor.
  3. Coller le code, cliquer sur Sauvegarder puis Ajouter au chart.
  4. Régler les inputs selon votre style (voir Paramètres clés).

Conseils : Activer seulement 3–4 HTFs à la fois pour garder le chart lisible. Combiner avec un daily open 8:30 ET pour le modèle Algorithmic Academy.
