Cours complet — Temps & Cycles

Quarterly Theory

Le temps est fractal. True Opens, AMDX/XAMD, cycles Yearly → Micro, SSMT, AOI et modeles d'entree. Le meme principe structurel se repete de l'annee au cycle de 22 minutes.

Qu'est-ce que la Quarterly Theory ?

La Quarterly Theory divise chaque cycle de temps en 4 quartiers (Q1 Accumulation, Q2 Distribution/Expansion, Q3 Re-accumulation, Q4 Distribution finale). Cette structure fractale se repete a tous les niveaux : annuel, mensuel, hebdomadaire, journalier, 90 minutes et micro (22 minutes).

Pane Sessions (Rich Bvwy)

Un pane separateur affiche les sessions en blocs colores : Asia (18:00-00:00), London (00:00-06:00), NYAM (06:00-12:00) et NYPM (12:00-18:00). Chaque session est divisee en 4 quartiers de 90 minutes, eux-memes subdivises en quartiers micro de ~22 minutes.

Cycles Overlay

Des boxes sont tracees directement sur le chart (force_overlay) pour visualiser les cycles Yearly, Monthly, Weekly, Daily, 90M et Micro. Chaque cycle est colore selon son quartier (Q1-Q4) avec transparence configurable.

True Opens

Lignes horizontales marquant les True Opens de chaque niveau : TMO (Monthly), TWO (Weekly), TDO (Daily), 09:30 (NY Open), T90 (90M True Open) et TMSO (Micro True Open). Le prix par rapport au True Open donne le biais directionnel.

Sessions et Quartiers

Q1 — Accumulation

Premiere phase du cycle. Le prix construit un range, les institutions accumulent des positions. C'est la phase ou le marche "prepare" le mouvement. Couleur grise par defaut.

Q2 — Distribution / Expansion

Le mouvement directionnel principal. Le prix sort du range Q1 dans une direction. C'est souvent la phase la plus volatile et profitable. Couleur rouge par defaut.

Q3 — Re-accumulation

Phase de consolidation apres Q2. Le prix retrace ou consolide avant le dernier mouvement. Opportunite de re-entree dans la tendance. Couleur verte par defaut.

Q4 — Distribution Finale

Derniere phase du cycle. Le prix atteint son objectif final ou reverse. C'est le moment de prendre les profits. Couleur bleue par defaut.

Comment Utiliser
  • Above/Below True Open : Si le prix est au-dessus du True Open (TMO/TWO/TDO), le biais est haussier pour ce cycle. En-dessous, biais baissier.
  • Confluence multi-niveaux : Quand tous les niveaux (Monthly, Weekly, Daily) sont "Above", la confluence est maximale pour un long. L'inverse pour un short.
  • Timing avec les quartiers : Entrez en Q2 (expansion) dans la direction du biais. Evitez Q1 (accumulation — pas de direction claire) et Q4 (fin de mouvement).
  • Pane visuel : Le pane en bas du chart montre visuellement ou vous etes dans la session et le quartier. Utile pour savoir combien de temps il reste avant le prochain quartier.
  • Alignement 18:00 ET : La journee commence a 18:00 ET (debut session Asia). Tous les cycles sont alignes sur cette reference pour respecter la structure ICT.
  • 09:30 comme reference : Le True Open 09:30 (ouverture NYSE) est un niveau cle intraday. Le prix au-dessus = biais haussier pour NYAM/NYPM.

Installation
  • 1. Telechargez le fichier .pine via le bouton ci-dessus
  • 2. Ouvrez TradingView et allez dans l'editeur Pine Script (icone {} en bas)
  • 3. Creez un nouveau script, collez le code, et cliquez sur "Ajouter au graphique"
  • 4. L'indicateur s'affiche comme un pane separateur (overlay=false) avec les blocs de sessions
  • 5. Les cycles overlay (boxes) apparaissent directement sur le chart principal via force_overlay
  • 6. Configurez les cycles a afficher et les couleurs dans les parametres
