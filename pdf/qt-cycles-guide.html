Quarterly Theory Cycles — Sessions + Cycles + True Opens

Indicateur Pine Script v6 — Pane + Overlay — Base sur Rich Bvwy + QT Clone v5

1 Introduction

Le Quarterly Theory Cycles est un indicateur Pine Script v6 qui implemente la Quarterly Theory complete : chaque cycle de temps est divise en 4 quartiers (Q1-Q4), de l'annuel au micro (22 minutes). Il combine un pane visuel des sessions (Rich Bvwy) avec des cycles overlay sur le chart et une table Above/Below pour le biais.

Pourquoi c'est important ?

La Quarterly Theory est le modele de timing ICT le plus puissant. Savoir dans quel quartier vous etes (accumulation, expansion, re-accumulation, distribution) a chaque echelle de temps permet de timer les entrees et d'eviter les faux signaux. Les True Opens donnent la direction.

2 La Quarterly Theory

2.1 — Le Principe Fractal

Chaque cycle de temps se divise en 4 quartiers avec un comportement previsible. Ce pattern est fractal — il se repete identiquement du niveau annuel au niveau micro :

Q1 — Accumulation

Le marche construit un range. Les institutions accumulent des positions. Pas de direction claire. Phase de "preparation".

Q2 — Expansion

Le mouvement directionnel principal. Sortie du range Q1. Phase la plus volatile et profitable. C'est ici qu'il faut trader.

Q3 — Re-accumulation

Consolidation apres Q2. Le prix retrace ou consolide. Opportunite de re-entree dans la tendance etablie en Q2.

Q4 — Distribution

Phase finale. Le prix atteint son objectif ou reverse. Moment de prendre les profits, pas d'initier de nouvelles positions.

3 Le Pane Sessions

3.1 — Affichage

L'indicateur s'affiche comme un pane separateur (overlay=false) sous le chart. Chaque session est representee par un bloc colore avec son nom (ASIA, LDN, NYAM, NYPM). A l'interieur, les quartiers 90M et micro sont visibles.

3.2 — Les 4 Sessions Journalieres

ASIA (18:00 - 00:00 ET)

Q1 du jour. Session d'accumulation. Le range forme ici definit souvent la liquidite qui sera prise plus tard.

LDN (00:00 - 06:00 ET)

Q2 du jour. Premiere expansion. London prend souvent la liquidite d'un cote du range asiatique.

NYAM (06:00 - 12:00 ET)

Q3 du jour. New York AM peut continuer le move de London ou creer un retracement. Fenetres macro 09:45-10:15.

NYPM (12:00 - 18:00 ET)

Q4 du jour. Distribution finale. Le prix atteint ses objectifs journaliers ou reverse pour le lendemain.

3.3 — Alignement 18:00 ET

La journee de trading ICT commence a 18:00 ET (debut de la session Asia), pas a minuit. L'indicateur affiche une ligne verticale a 18:00 pour marquer le debut de chaque nouvelle journee de trading. Tous les cycles sont alignes sur cette reference.

4 True Opens

4.1 — Principe

Le True Open est le prix d'ouverture de chaque cycle. C'est le niveau de reference pour determiner le biais : si le prix est au-dessus, le biais est haussier pour ce cycle. En-dessous, baissier.

EXEMPLE PRATIQUE

La table affiche :

  • TMO = Above, TWO = Above, TDO = Above
  • 09:30 = Above, T90 = Below

Interpretation : Tous les niveaux HTF sont Above = fort biais haussier. Le T90 Below indique un retracement temporaire dans le quartier 90M courant. Attendez que le prix repasse Above le T90 pour entrer long, ou cherchez un setup OTE dans la zone discount du quartier.

5 Table Above/Below

5.1 — Fonctionnement

La table affiche pour chaque cycle si le prix actuel est Above (au-dessus) ou Below (en-dessous) de son True Open. La position est configurable (defaut: Middle Right).

5.2 — Lecture du Biais

La regle est simple :

  • Tous Above : Confluence haussiere maximale. Cherchez uniquement des longs.
  • Tous Below : Confluence baissiere maximale. Cherchez uniquement des shorts.
  • HTF Above + LTF Below : Retracement temporaire dans une tendance haussiere. Opportunite d'achat.
  • HTF Below + LTF Above : Retracement temporaire dans une tendance baissiere. Opportunite de vente.
  • Mixte : Pas de confluence claire. Attendez un alignement ou tradez le range.

7 Strategies d'Utilisation

7.1 — Trader le Q2

Le Q2 est la phase d'expansion — c'est la ou le mouvement directionnel se produit. A chaque echelle, attendez la fin du Q1 (accumulation) et entrez au debut du Q2 dans la direction du biais (Above/Below True Open). Le Q2 offre le meilleur rapport risque/rendement.

7.2 — True Open comme Reference

Le True Open est votre boussole directionnelle. Si le prix est Above le TDO et le TWO, le biais est clairement haussier. Cherchez des longs pendant les Q2 et Q3 des sessions. Si Below, cherchez des shorts.

7.3 — Confluence des Cycles

Le setup optimal est quand plusieurs niveaux de cycles sont en Q2 simultanement. Par exemple : Weekly Q2 (mardi) + Daily Q2 (London) + 90M Q2 = triple confluence d'expansion. C'est le moment de prendre les trades les plus agressifs.

7.4 — Combinaison avec OTE / DRT

Utilisez la Quarterly Theory pour le timing ("quand") et les indicateurs de niveaux (DRT, DR OTE) pour le prix ("ou"). Le setup ideal : prix dans la zone OTE + debut de Q2 + Above True Open.

7.5 — Eviter les Pieges

  • Ne tradez pas en Q1 : C'est la phase d'accumulation, le prix va dans les deux directions. Attendez Q2.
  • Mefiance en Q4 : Le mouvement est souvent termine. Prenez vos profits, ne rentrez pas.
  • Vendredi (Weekly Q4) : Journee de distribution. Les moves sont souvent des faux signaux pour le lundi.
