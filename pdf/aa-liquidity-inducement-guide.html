AA — Market Structure + Inducements

Indicateur Pine Script v6 — ChoCh, BoS, LQDT, IDMT, UAlgo IDM — Sans librairie externe

1 Introduction

L'indicateur AA — Market Structure + Inducements est un outil clean tout-en-un qui detecte automatiquement la structure de marche (ChoCh/BoS/LQDT), les inducements pivot-based (IDMT) et les micro-inducements UAlgo (inside-bar + leg tracking) directement sur votre chart TradingView.

Contrairement a la version precedente, cet indicateur n'utilise aucune librairie externe. Tous les pivots sont calcules nativement via ta.pivothigh et ta.pivotlow.

Nouveautes de la version Clean

  • Zero dependance : Plus besoin de la librairie mickes/PriceAction
  • BoS → LQDT : Un BoS se transforme en LQDT quand le prix sweep le niveau sans cloture au-dela
  • Structure Timeframe MTF : Input dedie pour calculer les pivots sur un HTF et les afficher sur le LTF
  • Code ~330 lignes : Beaucoup plus leger et maintenable

2 Market Structure

La structure est detectee via des pivots natifs a 3 periodes differentes pour ChoCh, BoS et IDMT.

ChoCh — Change of Character

Pivots a longue periode (defaut 30). Le prix casse un pivot dans la direction opposee a la tendance. Signal de retournement. Quand un ChoCh se produit, les BoS en attente sont effaces.

BoS — Break of Structure

Pivots a courte periode (defaut 1). Le prix casse un pivot dans la direction de la tendance. Ligne dashed etendue. Si le prix cloture au-dela → BoS confirme.

BoS → LQDT (Liquidite)

Quand un BoS est en attente et que le prix fait un wick a travers le niveau mais cloture de l'autre cote, le BoS est reclasse en LQDT (liquidite). La ligne passe en dotted violet. C'est une prise de liquidite — le prix a piege les breakout traders.

Tendance (Trend)

L'indicateur maintient un trend interne ("Up Trend" / "Down Trend") mis a jour a chaque ChoCh. Ce trend determine :

  • Quel cote les BoS sont cherches (highs en uptrend, lows en downtrend)
  • Quel cote les IDMT sont places (lows en uptrend, highs en downtrend)
  • Comment les UAlgo legs sont trackes

3 Structure MTF (Multi-Timeframe)

L'input Structure Timeframe permet de calculer tous les pivots (ChoCh, BoS, IDMT) sur un timeframe superieur via request.security().

Exemple : Sur un chart 1m, selectionnez "15" pour voir la structure du 15m. Les ChoCh/BoS/LQDT du 15m seront dessines directement sur votre chart 1m, permettant un timing precis tout en respectant la structure HTF.

Laissez vide pour utiliser le timeframe du chart (comportement par defaut).

4 Inducements (IDMT) — Systeme Pivot

Detection : Pivots a periode configurable (defaut 3). En uptrend, le premier pivot low apres un BoS/ChoCh est marque comme IDMT. En downtrend, le premier pivot high.

Lifecycle :

  • Creation : Nouveau pivot dans la direction de pullback → label "IDMT" + ligne dotted gris
  • Extension : La ligne se prolonge barre par barre tant que l'IDMT est actif
  • Remplacement : Un nouveau pivot de meme type remplace l'ancien (delete + nouveau)
  • Invalidation (Sweeps) : Wick a travers + cloture de l'autre cote → l'IDMT est swept
  • Invalidation (Total) : Tout contact avec le niveau → IDMT invalide
  • Suppression : Si le prix cloture au-dela de l'IDMT, la ligne est supprimee (le prix a traverse sans piege)

5 UAlgo IDM (Inside-Bar + Legs)

Principe : Systeme independant base sur le tracking des legs de prix et les inside bars. Les inside bars sont ignorees (pas de nouvelle information). Le systeme traque les leg highs/lows et detecte les pullbacks.

Mecanisme :

  • Mother candle : Le high/low de reference. Une barre dont le range est contenu dans la mother candle = inside bar (ignoree).
  • En uptrend : Si le prix fait un nouveau leg high, tout pullback precedent est confirme comme IDM bullish (support).
  • En downtrend : Si le prix fait un nouveau leg low, tout pullback precedent est confirme comme IDM bearish (resistance).
  • Trend flip : Si le prix casse le leg low en uptrend (ou leg high en downtrend), le trend flip et les pullbacks sont reinitialises.

EXEMPLE — UALGO IDM EN UPTREND

1. Le prix monte de 100 a 110 (leg high = 110)

2. Pullback a 105 (enregistre comme potentiel IDM)

3. Le prix remonte a 112 (nouveau leg high) → le pullback a 105 est confirme : IDM a 105 (rouge, support)

4. Plus tard, le prix redescend a 104 → IDM ok (swept, la liquidite des acheteurs a 105 a ete prise)

5. C'est souvent le moment d'un reversal ou d'une continuation forte apres cette prise de liquidite.

6 Strategies d'Utilisation

6.1 — Setup Reversal (ChoCh + LQDT)

  • Identifiez un ChoCh (retournement de tendance)
  • Attendez un BoS → LQDT dans la nouvelle direction (piege des breakout traders)
  • Entrez dans la direction du ChoCh apres la confirmation LQDT
  • Stop sous/au-dessus du LQDT, target = prochain IDMT ou niveau de structure

6.2 — Setup Continuation (BoS + IDMT)

  • En tendance confirmee (BoS), attendez le retracement IDMT
  • Quand l'IDMT est swept (en mode Sweeps), cherchez une entree dans la direction du trend
  • Target : prochain BoS ou niveau de structure

8 Notes Techniques

  • Version : Pine Script v6
  • Dependance : Aucune (pivots natifs)
  • Overlay : Oui (directement sur le chart)
  • Max bars back : 5000
  • Limites : 500 labels + 500 lignes

  • UAlgo limit : 50 IDM actifs simultanes avec cleanup auto (array.shift)
