AA Liquidity & Inducements

Indicateur Pine Script v6 — Structure, Liquidite, Inducement — mickes/PriceAction + UAlgo

1 Introduction

L'indicateur AA Liquidity & Inducements est un outil tout-en-un qui detecte automatiquement la structure de marche (BoS/ChoCh), les zones de liquidite (Grabs, Sweeps, BSL/SSL, Equal H/L, Turtle Soups) et les inducements (pieges de liquidite) sur votre chart TradingView.

Il combine deux moteurs : la librairie mickes/PriceAction/4 pour la structure formelle, et le systeme UAlgo pour les micro-inducements via inside bars.

Pourquoi cet indicateur ?

En ICT/SMC, comprendre ou se trouve la liquidite et quels niveaux sont des pieges (inducements) est la cle pour anticiper les mouvements du market maker. Cet indicateur automatise cette detection.

2 Market Structure

La structure est detectee via des pivots (swing highs et swing lows) avec une longueur configurable (defaut: 5 barres gauche/droite).

BoS — Break of Structure

Le prix casse un pivot dans la direction de la tendance. Uptrend : nouveau high > previous high. Downtrend : nouveau low < previous low. Signal de continuation.

ChoCh — Change of Character

Le prix casse un pivot dans la direction opposee a la tendance. Signal de retournement. C'est la premiere etape d'un reversal potentiel.

Tendance

L'indicateur maintient un trend interne (1 = bullish, -1 = bearish) qui est mis a jour a chaque BoS (continuation) ou ChoCh (flip). Ce trend influence comment les equal H/L sont classifies ($$$ ou IDM) et comment les inducements sont crees.

3 Les 5 Types de Liquidite

3.1 — Grabs ($$$)

Detection : Le prix fait un wick a travers un pivot, puis cloture de l'autre cote (retour). C'est une prise de liquidite rapide — les stops ont ete touches mais le prix est revenu.

Visuellement : Zone coloree entre le pivot et le wick, avec label "$$$".

Parametres : Pivot Left/Right (3/3), Lookback (5), Timeframe (configurable).

3.2 — Big Grabs ($$$)

Identique aux Grabs mais avec des pivots plus larges (defaut: 10/10). Detecte les prises de liquidite HTF (Higher Timeframe). Utilisez un timeframe superieur pour encore plus de precision.

3.3 — Sweeps ($)

Detection : Le prix fait un wick a travers un pivot ET cloture au-dela. Contrairement au grab, le prix ne revient pas — c'est un sweep confirme.

Couleurs : Bullish (sweep d'un low = vert) / Bearish (sweep d'un high = rouge).

Filtre : Les sweeps qui coincident avec un BoS ne sont pas affiches (c'est de la structure, pas de la liquidite).

3.4 — Turtle Soups

Detection : Un sweep suivi d'un ChoCh dans la direction opposee. C'est le setup ICT classique — le prix prend la liquidite puis reverse.

Confirmation : Option pour exiger un ChoCh confirme (recommande ON).

Parametres : Pivot (1/1), Lookback (5), Timeframe configurable.

3.5 — Equal Highs/Lows

Detection : Deux pivots dont le prix est dans une tolerance ATR (defaut: 0.5x ATR). Ce sont des double tops/bottoms qui concentrent la liquidite.

Classification par tendance :

  • En downtrend, des equal highs = $$$ (liquidite buyside) — le prix ira les chercher
  • En downtrend, des equal lows = IDM (inducement) — piege pour les vendeurs
  • En uptrend, des equal lows = $$$ (liquidite sellside)
  • En uptrend, des equal highs = IDM (inducement) — piege pour les acheteurs

Sweep : Quand le prix prend un equal H/L classe comme IDM, il est marque comme $$$ (liquidite prise).

4 BSL & SSL (External Liquidity)

BSL (Buyside Liquidity) : Pools au-dessus des swing highs de structure. Lignes pointillees vertes etendues vers la droite. Effacees quand le prix les atteint.

SSL (Sellside Liquidity) : Pools en-dessous des swing lows de structure. Lignes pointillees rouges. Meme comportement.

Show Last N : Configurable — n'affiche que les N derniers pools pour garder le chart propre (defaut: 1).

5 Inducements (IDM) — Double Systeme

5.1 — Retracement IDM (mickes)

Principe : Apres un BoS ou ChoCh, le premier pullback (premier pivot dans la direction opposee) est marque comme inducement. C'est le niveau ou les "early traders" se font pieger.

Lifecycle :

  • Creation : Premier pivot de retracement apres un structure break
  • Actif : Ligne pointillee etendue vers la droite avec label "IDM"
  • Swept : Quand le prix atteint le niveau → ligne arretee, confirmation que la liquidite a ete prise
  • Invalide : Au prochain BoS/ChoCh → ligne grisee, n'est plus pertinent

Parametres : Pivot (1/1), Lookback (5), Timeframe, couleurs bull/bear, option garder les invalides.

5.2 — UAlgo IDM (inside-bar + legs)

Principe : Systeme independant base sur le tracking des legs de prix et les inside bars. Quand le prix fait un pullback dans une leg puis que la leg continue (nouveau high/low), le pullback est confirme comme inducement.

Mecanisme detaille :

  • Inside bar : Barre dont le high est sous le high precedent ET le low au-dessus du low precedent. Ces barres sont ignorees (pas de nouvelle information).
  • Leg tracking : En uptrend, le systeme traque le leg high. Un pullback (low plus bas) est enregistre comme potentiel IDM.
  • Confirmation : Quand le prix fait un nouveau leg high, le pullback precedent est confirme comme IDM (label "IDM ✗").
  • Sweep : Quand le prix revient et prend l'IDM → "IDM ✓" (ligne pointillee, couleur attenuee).
  • Trend flip : Si le prix casse le leg low (en uptrend), le trend flip et les pullbacks sont reinitialises.
EXEMPLE — UALGO IDM EN UPTREND

1. Le prix monte de 100 a 110 (leg high = 110)

2. Pullback a 105 (enregistre comme potentiel IDM)

3. Le prix remonte a 112 (nouveau leg high) → le pullback a 105 est confirme : IDM ✗ a 105

4. Plus tard, le prix redescend a 104 → IDM ✓ (swept, la liquidite des acheteurs a 105 a ete prise)

5. C'est souvent le moment d'un reversal ou d'une continuation forte apres cette prise de liquidite.

6 Strategies d'Utilisation

6.1 — Setup Reversal (Phase 1 du 2-Phase Theorem)

Les IDM sont la Phase 1 du 2-Phase Inducement Theorem :

  • Identifiez un IDM non-swept (IDM ✗) pres d'un orderblock valide
  • Attendez que le prix sweep l'IDM (IDM ✓) = Phase 1 complete
  • Cherchez un ChoCh apres le sweep = MSS (Market Structure Shift)
  • Entrez dans la direction du ChoCh avec stop sous/au-dessus du sweep

6.2 — Setup Continuation (IPB)

Apres un reversal confirme (2 phases), tradez les continuations :

  • Apres un BoS, attendez le retracement IDM (mickes)
  • Quand l'IDM est swept, cherchez une entree dans la direction du trend
  • Target : prochain BSL/SSL ou equal H/L marque comme $$$

6.3 — Turtle Soup

Le setup le plus propre :

  • Le prix sweep un pivot (Turtle Soup detecte)
  • Un ChoCh confirme le retournement
  • Entree sur le retest de la zone de sweep
  • Stop sous le sweep, target = prochain pool de liquidite oppose

8 Notes Techniques

  • Version : Pine Script v6
  • Dependance : mickes/PriceAction/4 (importee automatiquement)
  • Types custom : EqualPivotInducement, Liquidity, LiquidityGrabs, LiquiditySweeps, RetracementInducement, ExternalLiquidity, UAlgoIDM
  • Methods : drawUAlgo(), checkSweepUAlgo(), LiquidationGrabbed(), LiquidationSwept(), etc.
  • Multi-TF : Chaque module utilise request.security() avec son propre input timeframe
  • Limites : 500 labels + 500 lignes max. Les anciens objets sont nettoyes automatiquement.
  • UAlgo limit : 50 IDM actifs simultanes. Les plus anciens sont supprimes en premier.
