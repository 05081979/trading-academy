DRT MTF — Dealing Range Theory

Indicateur Pine Script v6 — Multi-Timeframe — Base sur le code mickes

1 Introduction

Le DRT MTF (Dealing Range Theory Multi-Timeframe) est un indicateur Pine Script qui identifie automatiquement les Dealing Ranges — les zones de prix ou les institutions ont execute des transactions — sur 8 timeframes simultanement.

Base sur la theorie des Dealing Ranges de mickes, cet indicateur detecte les moments ou le prix "prend" la liquidite d'un pivot precedent, creant ainsi un range institutionnel avec des niveaux cles : High, Low, 50% (Equilibrium), 75% et 25%.

Pourquoi c'est important ?

Les Dealing Ranges revelent les zones ou les market makers et algorithmes institutionnels ont execute des ordres. Le prix a tendance a revenir vers l'equilibre (50%) de ces ranges, et les niveaux 75%/25% servent de zones d'entree/sortie optimales.

2 Theorie des Dealing Ranges

2.1 — Formation d'un Dealing Range

Un Dealing Range se forme en deux etapes :

  • Etape 1 — Detection des pivots de liquidite : L'indicateur identifie les pivots hauts (buyside liquidity) et bas (sellside liquidity) avec une sensibilite configurable (Liquidity Length).
  • Etape 2 — Prise de liquidite : Lorsqu'un nouveau pivot majeur (Pivot Length) depasse un pivot de liquidite precedent, il "prend" cette liquidite. Le High du nouveau pivot et le Low (ou inversement) definissent le Dealing Range.

2.2 — Les 5 Niveaux

High (100%)

Sommet du Dealing Range. Niveau ou la liquidite buyside a ete prise. Resistance institutionnelle.

75% (Deep Premium)

Zone premium profonde. Ideal pour les shorts. Si le prix atteint ce niveau et rejette, forte probabilite de retour vers EQ.

50% — Equilibrium (EQ)

Le coeur du range. Le prix est naturellement attire vers ce niveau. Separe Premium (au-dessus) et Discount (en-dessous).

25% (Deep Discount)

Zone discount profonde. Ideal pour les longs. Meilleur rapport risque/rendement pour les achats.

Low (0%)

Base du Dealing Range. Niveau ou la liquidite sellside a ete prise. Support institutionnel.

2.3 — Premium vs Discount

Zone Premium (au-dessus de EQ) : Le prix est relativement "cher". Les traders institutionnels cherchent a vendre dans cette zone. Strategiquement, c'est la zone pour les positions short.

Zone Discount (en-dessous de EQ) : Le prix est relativement "pas cher". Les institutions cherchent a acheter. Zone ideale pour les positions long.

Equilibrium (EQ) : Le point de basculement. Un prix qui traverse l'EQ change de regime — de premium a discount ou inversement. C'est souvent un objectif de prix naturel.

L'indicateur utilise request.security() pour calculer le DRT sur chaque timeframe independamment, puis affiche tous les resultats sur votre chart actuel. Cela permet de voir la structure institutionnelle a travers toutes les echelles de temps.

EXEMPLE PRATIQUE

Vous etes sur un chart 5 minutes. L'indicateur affiche simultanement :

  • Le DRT 1H avec EQ a 1.0850 (orange)
  • Le DRT 4H avec EQ a 1.0820 (rouge)
  • Le tableau montre : 1H = Discount, 4H = Discount

Interpretation : Les deux TF sont en discount = biais haussier. Cherchez un long avec un objectif vers les EQ respectifs.

4 Tableau de Synthese

Le tableau en haut a droite du chart affiche en temps reel pour chaque TF actif :

  • TF — Le timeframe avec sa couleur dediee
  • Zone — La position du prix : Premium, Discount, Above (au-dessus du range), Below (en-dessous)
  • EQ — Le prix exact de l'equilibre (50%) pour ce TF

Lecture du Tableau pour le Biais

Si la majorite des TF affichent Discount → le prix est globalement "pas cher" → biais haussier.

Si la majorite affichent Premium → le prix est "cher" → biais baissier.

Si les TF sont mixtes → pas de biais clair, attendre une convergence ou trader le range.

6 Strategies d'Utilisation

6.1 — Confluence Multi-TF

Regle : Plus il y a de TF alignes dans la meme zone (tous Discount ou tous Premium), plus le signal est fort.

  • 3+ TF en Discount → fort biais long, chercher des achats au 25%
  • 3+ TF en Premium → fort biais short, chercher des ventes au 75%
  • TF HTF (D/W) en Discount + TF LTF (15m/1H) en Premium → retracement temporaire dans une tendance haussiere, attendre le retour en discount sur le LTF

6.2 — EQ comme Objectif

Quand le prix est au 25% (deep discount), le premier objectif est l'EQ (50%). C'est un objectif conservateur mais a haute probabilite. L'inverse pour les shorts depuis le 75%.

6.3 — Combinaison DRT + ICT Macros

La meilleure utilisation du DRT est en combinaison avec les fenetres macro ICT (Module 14). Le DRT vous donne le "ou" (quel niveau), les macros vous donnent le "quand" (quelle fenetre temporelle).

Setup ideal : Prix au 25% du DRT 1H + Macro 09:45-10:15 (NY Open) → entree long avec stop sous le Low du DR, target EQ.

6.4 — Rejection aux Niveaux

Les niveaux DRT (surtout High, Low et EQ) agissent comme des S/R dynamiques. Cherchez des rejections (wicks, FVG, order blocks) a ces niveaux pour confirmer vos entrees.
