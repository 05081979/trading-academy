Dealing Range OTE MTF — Swings + OTE + Zones

Indicateur Pine Script v6 — Multi-Timeframe — Detection via ta.valuewhen

1 Introduction

Le Dealing Range OTE MTF est un indicateur Pine Script v6 qui identifie le Dealing Range actuel en detectant les derniers Swing High et Swing Low via ta.valuewhen. Il trace ensuite les niveaux OTE (Optimal Trade Entry) — les retracements Fibonacci utilises par les institutions — et les zones Premium/Discount sur 8 timeframes simultanement.

Pourquoi c'est important ?

Les niveaux OTE (0.618-0.79 et 0.21-0.382) sont les zones ou les algorithmes institutionnels placent leurs ordres. Combiner ces niveaux avec le Dealing Range multi-TF permet de trouver les zones d'entree a haute probabilite avec un rapport risque/rendement optimal.

2 Detection des Swings

2.1 — Methode

L'indicateur utilise une approche en deux etapes pour detecter le Dealing Range :

  • Etape 1 : ta.highest(high, length) et ta.lowest(low, length) identifient les extremes sur le lookback.
  • Etape 2 : ta.valuewhen(high == rangeHigh, high, 0) capture le vrai Swing High — le prix exact de la barre qui a cree le plus haut.

Le Dealing Range est defini entre le Swing High et le Swing Low detectes. Cela donne un range plus reactif que les methodes basees sur les pivots traditionnels.

2.2 — Lookback Configurable

Range Lookback Bars (defaut: 20). Ce parametre controle la fenetre de detection :

  • 5-10 barres : Ranges tres courts, reactifs — ideal pour le scalping
  • 20 barres (defaut) : Bon equilibre entre reactivite et stabilite
  • 50-100 barres : Ranges larges, plus stables — ideal pour le swing trading

Zone OTE Classique ICT

La zone OTE premium se situe entre 0.618 et 0.79. C'est la zone ideale pour les shorts dans un marche baissier. La zone OTE discount est entre 0.21 et 0.382 — ideale pour les longs dans un marche haussier. Le 0.705 (premium) et le 0.295 (discount) sont les midpoints de ces zones OTE.

4 Fonctionnement Multi-Timeframe

Le Dealing Range est calcule independamment sur chaque TF via request.security(). Cela signifie que le 1H peut etre en Discount tandis que le Daily est en Premium — cette information est essentielle pour le biais.

5 Tableau de Synthese

Le tableau en haut a droite du chart affiche en temps reel pour chaque TF actif :

  • TF — Le timeframe avec sa couleur dediee
  • Zone — La position du prix : Premium, Discount, Above (au-dessus du range), Below (en-dessous)
  • EQ — Le prix exact de l'equilibre (50%) pour ce TF
EXEMPLE PRATIQUE

Vous etes sur un chart 5 minutes NQ :

  • 1H = Discount, EQ = 18,450
  • 4H = Discount, EQ = 18,500
  • Prix actuel = 18,320 (au niveau OTE 0.295 du 1H)

Interpretation : Deux TF alignes en discount + prix dans la zone OTE discount = setup long optimal. Target EQ 1H (18,450), puis EQ 4H (18,500).

7 Strategies d'Utilisation

7.1 — Entree OTE Classique

Long : Quand le 1H et 4H sont en Discount, attendez que le prix atteigne la zone OTE discount (0.21-0.382) du 1H. Entrez long avec stop sous le Low du DR. Target : EQ (50%) puis 0.618.

Short : Quand le 1H et 4H sont en Premium, attendez la zone OTE premium (0.618-0.79). Entrez short avec stop au-dessus du High. Target : EQ puis 0.382.

7.2 — Confluence Multi-TF

Plus il y a de TF alignes dans la meme zone, plus le signal est fort :

  • 3+ TF en Discount = fort biais long, entree OTE discount
  • 3+ TF en Premium = fort biais short, entree OTE premium
  • TF mixtes = pas de biais clair, trader le range ou attendre

7.3 — EQ comme Premier Objectif

L'EQ (50%) est toujours le premier objectif depuis un niveau OTE. C'est un target conservateur mais a haute probabilite. Le prix est naturellement attire vers cet equilibre.

7.4 — Combinaison avec d'autres Indicateurs

Le DR OTE est particulierement puissant combine avec :

  • DRT MTF (Module 13) : Le DRT donne les ranges institutionnels, le DR OTE donne les niveaux OTE
  • ICT Macros (Module 14) : Timing des entrees dans les fenetres macro
  • QT Cycles (Module 22) : Le quartier Q2 est le meilleur moment pour entrer a un niveau OTE
